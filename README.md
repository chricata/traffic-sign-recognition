# traffic-sign-recognition
Mobile app for real-time traffic sign recognition.

This project requires the ATSD Version 1 traffic sign dataset, DOI: 10.53177/ATSD.V1_0.
The dataset can be acquired by visiting the official Asfinag website and filling out a form (https://contentportal.asfinag.at/ATSD/form).
A download link will be sent to the provided E-Mail address.
After downloading the dataset, please extract the Scenes and Signs folders so the structure looks like this:

traffic-sign-recognition
├── dataset
│   ├── scenes
│   └── signs
...
